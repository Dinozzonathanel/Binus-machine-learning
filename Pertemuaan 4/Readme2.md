# Laporan Analisis Supervised Learning, Regresi dengan data "Top 50 Cryptocurrency" - Dinozzo Nathanael Budiman

## Domain Proyek 
Melakukan sebuah analisis tentang regresi pada data set "Top 50 Cryptocurrency" untuk memahami lebih lagi tentang regresi di dalam machine learning

### Latar Belakang 
Sebagai percobaan melakukan Supervised learning (regression) meggunakan data yang ditemukan dari kaggle melainkan data yang diberikan di Blog.Zulma

## Business Understanding
Analisis sederhana yang dilakukan untuk memahami lebih lagi tentang Supervised learning (regression) dan membuat model yang bagus dengan mengunakan supervised learning tersebut

### Problem Statements
Bagimana saya dapat melakukan Supervised Learning dan mencari data untuk melakukannya 

### Goals
Belajar lebih lagi mengenai materi Machine learning dan yang difokuskan sekarang merupakan Supervised Learning (Regresi) dengan cara menggunakan data "Top 50 Cryptocurrency" yang disediakan

### Solution Statements
Menggunakan Kaggle untuk mencari data, menggunakan google collab untuk menjalani kode dan untuk mengimpor data, dan menggunakan github untuk mengupload hasil dan laporan
